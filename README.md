# LONG ECU TUNER V8 WEB PRO

Mở `index.html` để chạy giao diện ECU tuner web.

Có:
- Dashboard kiểu ECU tuner
- Fuel Map 500–15,000 RPM x TPS 0–100%
- Ignition Map
- Auto Tune AFR correction
- RPM limit tới 15,000
- Simulation
- BLE scan thử nghiệm
- Save local / Export JSON / Import JSON
- Giao diện responsive cho iPhone Safari

Lưu ý: BLE hiện chỉ là lớp thử nghiệm chọn thiết bị. Không gửi map vào ECU thật khi chưa xác định đúng protocol/checksum và firmware ESP32.
